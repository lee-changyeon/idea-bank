# 아이디어뱅크 사용 안내서

> 아이디어를 적어 두고, **"이 아이디어는 이 날짜에 이미 내게 있었다"** 는 것을 나중에 증명할 수 있게 해 주는 앱입니다.
>
> 대상: 아이디어를 등록하려는 모든 분 · 작성 기준: 설계안 v0.1 (2026-11-18)

---

## 1. 이런 분께 필요합니다

- 좋은 아이디어가 떠올랐는데 **특허를 내기는 어렵거나 부담스러운** 분
- 기획안, 사업 모델, 디자인 콘셉트, 노하우처럼 **특허로 보호받기 힘든 아이디어**를 가진 분
- 나중에 "그건 내가 먼저 생각한 거야"라고 말해야 할 때 **근거를 남겨 두고 싶은** 분
- 여러 사람이 함께 작업하면서 **누가 언제 무엇을 제안했는지** 기록하고 싶은 팀

## 2. 한눈에 보는 사용 흐름

```
 ① 적는다        ② 등록한다         ③ 증명서를 받는다      ④ 필요할 때 꺼내 쓴다
 아이디어 작성 → [등록] 버튼 클릭 → 등록번호·확인서 발급 → 확인서·증명 파일 제출
```

어려운 설정은 없습니다. **적고, 등록 버튼을 누르면 끝**입니다. 날짜 증명은 앱이 알아서 처리합니다.

## 3. 시작하기

### 3.1 앱 실행

1. `idea-bank` 폴더의 **`run.bat`** 파일을 더블클릭합니다.
2. 검은 창이 뜨고 잠시 뒤 인터넷 브라우저가 자동으로 열립니다.
   - 브라우저가 열리지 않으면 주소창에 `http://localhost:8080` 을 입력하세요.
3. 앱을 쓰는 동안 검은 창은 **닫지 마세요.** (닫으면 앱이 꺼집니다)

### 3.2 화면 구성

화면 위쪽에 메뉴가 세 개 있습니다.

| 메뉴 | 하는 일 |
|------|---------|
| **✏️ 등록** | 새 아이디어를 적고 등록합니다 |
| **📁 보관함** | 등록한 아이디어를 찾아보고, 확인서를 받습니다 |
| **🔍 검증** | 등록 내용이 바뀌지 않았는지, 언제 등록됐는지 확인합니다 |

## 4. 아이디어 등록하기

### 4.1 입력 항목

| 항목 | 필수 | 적는 요령 |
|------|:----:|-----------|
| **제목** | ✅ | 한 줄로 핵심을 요약하세요. 예) "자전거 거치대 겸용 우산꽂이" |
| **내용** | ✅ | 형식 자유. 아래 「잘 적는 법」을 참고하세요 |
| **작성자** | 권장 | 본인 이름. 팀이면 함께한 사람 이름을 모두 적으세요 |
| **태그** | 선택 | 나중에 찾기 쉽도록. 예) `생활용품`, `자전거` |
| **첨부파일** | 선택 | 스케치, 사진, 기획서, 음성메모 등 (파일당 20MB까지) |
| **공인 시각 받기** | 기본 켜짐 | 켜 두세요. 외부 공인기관이 등록 시각을 보증해 줍니다 |

### 4.2 아이디어를 잘 적는 법

나중에 증거로 쓰려면 **"무엇을, 왜, 어떻게"** 가 드러나도록 적는 것이 좋습니다.

```
[무엇]  자전거 거치대와 우산꽂이를 하나로 합친 제품
[왜]    아파트 현관에 자전거와 우산이 따로 놓여 공간을 많이 차지함
[어떻게] 거치대 기둥 안쪽을 비워 우산을 세로로 꽂고,
        바닥 받침에 물받이를 둔다
[특징]  기둥 높이 조절 가능, 우산 4개까지 수납
```

- ✅ 구체적일수록 좋습니다. 그림 한 장이 긴 설명보다 나을 때가 많습니다.
- ✅ 생각이 완성되지 않았어도 지금 상태 그대로 등록하세요. **일찍 등록할수록 날짜가 앞섭니다.**
- ⚠️ 등록한 내용은 **고칠 수도, 지울 수도 없습니다.** (그래야 증거가 됩니다) 등록 전 한 번 더 읽어 보세요.

### 4.3 등록 버튼을 누르면

1. 앱이 내용을 바탕으로 **고유 지문(해시)** 을 만듭니다. 내용이 한 글자만 달라도 지문이 완전히 바뀝니다.
2. 이 지문을 **외부 공인 시각 인증 기관**에 보내 "지금 이 시각에 이 지문이 있었다"는 전자 서명을 받습니다.
   - 🔒 기관에는 **지문만** 보냅니다. 아이디어 내용은 내 컴퓨터 밖으로 나가지 않습니다.
3. 화면에 **등록번호**(예: `IB-20261118-000012`)와 등록 시각이 표시됩니다.

> 💡 **공인 시각이 "대기 중"으로 나온다면?**
> 인터넷 연결이 잠시 끊겼을 수 있습니다. 아이디어는 이미 안전하게 저장됐습니다.
> 보관함에서 해당 아이디어를 열고 **[공인 시각 다시 받기]** 를 누르세요.
> (단, 공인 시각은 버튼을 누른 그 시점으로 찍히므로 가능한 한 빨리 다시 받으세요)

## 5. 아이디어를 발전시켰을 때 — 개정판 등록

처음 아이디어를 고치고 싶을 때는 **수정이 아니라 "개정판"** 을 등록합니다.

1. **보관함**에서 원래 아이디어를 엽니다.
2. **[개정판 등록]** 을 누르면 기존 내용이 채워진 등록 화면이 열립니다.
3. 바뀐 부분을 고치고 등록합니다.

결과적으로 아래처럼 **발전 과정 전체가 날짜와 함께** 남습니다.

```
v1  2026-11-18  자전거 거치대 겸용 우산꽂이 (처음 아이디어)
 └ v2  2026-12-02  물받이 분리형 구조 추가
    └ v3  2027-01-15  높이 조절 방식 변경
```

> 처음 판(v1)은 그대로 남아 있으므로 "핵심 아이디어는 11월 18일에 이미 있었다"는 증명이 유지됩니다.

## 6. 보관함 — 찾아보기와 확인서 받기

### 6.1 찾기

- 위쪽 검색창에 제목·내용·태그의 단어를 입력하면 바로 걸러집니다.
- 태그를 누르면 같은 태그의 아이디어만 모아 봅니다.

### 6.2 아이디어 상세 화면에서 볼 수 있는 것

| 표시 | 의미 |
|------|------|
| 등록번호 | 이 아이디어의 고유 번호 |
| 등록 시각 | 내 컴퓨터에 등록된 시각 |
| **공인 시각** ✅ | 외부 공인기관이 보증한 시각 — **증거로는 이 시각이 가장 중요합니다** |
| 고유 지문(해시) | 64자리 영문·숫자. 내용이 바뀌면 이 값도 바뀝니다 |
| 개정 이력 | 이전 판·다음 판 목록 |

### 6.3 확인서 받기

**[확인서]** 버튼 → 인쇄용 화면이 열립니다.

- 브라우저의 **인쇄 → "PDF로 저장"** 을 선택하면 PDF 파일로 보관할 수 있습니다.
- 확인서에는 등록번호, 제목, 작성자, 등록 시각, 공인 시각, 고유 지문이 담깁니다.

### 6.4 증명 파일(zip) 내려받기

**[증명 파일 내려받기]** 버튼 → `IB-…-증명.zip` 파일이 저장됩니다. 안에는:

- 등록 원문
- 첨부파일 원본
- 공인기관의 전자 서명 파일
- 다른 사람이 직접 검증하는 방법 안내문

> 💡 **분쟁이나 제출이 필요할 때는 확인서(PDF)와 증명 파일(zip)을 함께 내세요.**
> 이 앱이 없는 사람도 안내문에 따라 증명 파일을 직접 검증할 수 있습니다.
> 증명 파일은 USB, 클라우드, 이메일 등 **다른 곳에도 복사해 두는 것**을 권장합니다.

## 7. 검증하기

**🔍 검증** 메뉴에서 세 가지를 확인할 수 있습니다.

| 기능 | 언제 쓰나요 | 방법 |
|------|-------------|------|
| **보관함 전체 점검** | 저장된 기록이 몰래 바뀌지 않았는지 확인할 때 | [전체 점검] 클릭 → ✅ 정상 / ❌ 이상 항목 표시 |
| **증명 파일 검증** | 누군가 제출한 증명 파일(zip)이 진짜인지 확인할 때 | zip 파일을 끌어다 놓기 |
| **파일로 등록일 찾기** | "이 스케치 파일을 언제 등록했더라?" 싶을 때 | 파일을 끌어다 놓기 → 등록된 아이디어와 날짜 표시 |

> 🔒 "파일로 등록일 찾기"는 파일을 서버로 보내지 않고, 브라우저 안에서 지문만 계산해 찾아봅니다.

## 8. 꼭 알아 두세요 (증명의 범위)

| 이 앱이 증명하는 것 ✅ | 이 앱이 증명하지 **못하는** 것 ❌ |
|------------------------|-----------------------------------|
| 그 날짜·시각에 **이 내용이 존재했다** | 내가 **세계 최초**로 생각했다 |
| 등록 후 **내용이 바뀌지 않았다** | 아이디어가 **새롭거나 가치 있다** |
| 내가 이 기록을 **보관하고 있었다** | 법적으로 **특허와 같은 독점권**을 가진다 |

- 중요한 분쟁이나 사업화를 앞두고 있다면 **변리사·변호사와 상담**하세요.
- 더 강한 증거가 필요하면 공증, 한국지식재산보호원의 「영업비밀 원본증명」 서비스를 함께 이용할 수 있습니다.
- 아이디어를 외부에 공개하면 이후 특허 출원이 어려워질 수 있습니다. 이 앱은 **내 컴퓨터에만 저장**하므로 공개에 해당하지 않습니다.

## 9. 자주 묻는 질문

**Q. 오타를 냈어요. 고칠 수 없나요?**
A. 고칠 수 없습니다. 증거로서의 가치가 바로 "고칠 수 없다"는 데 있기 때문입니다. 오타를 고친 **개정판**을 등록하세요. 처음 판의 날짜는 그대로 유지됩니다.

**Q. 잘못 등록한 아이디어를 지우고 싶어요.**
A. 지울 수 없습니다. 하나를 지우면 그 뒤 모든 기록의 연결 고리가 깨지도록 설계되어 있습니다. 필요하면 개정판에 "폐기"라고 적어 두세요.

**Q. 내 아이디어 내용이 인터넷으로 나가나요?**
A. 아니요. 외부 기관에는 64자리 지문만 보냅니다. 지문으로 원래 내용을 알아내는 것은 불가능합니다.

**Q. 인터넷이 없을 때도 쓸 수 있나요?**
A. 등록·보관·검색은 됩니다. 공인 시각만 "대기 중"이 되며, 인터넷이 연결되면 다시 받을 수 있습니다.

**Q. 컴퓨터를 바꾸면요?**
A. `idea-bank` 폴더 안의 **`data` 폴더**를 통째로 새 컴퓨터에 복사하면 됩니다. 정기적으로 다른 곳에 백업해 두세요.

**Q. 등록 시각과 공인 시각이 몇 초 다른데 괜찮나요?**
A. 정상입니다. 공인기관과 주고받는 데 걸리는 시간입니다. 증거로는 **공인 시각**을 쓰세요.

**Q. 공인 시각 인증 기관은 어디인가요?**
A. 기본으로 DigiCert(세계적인 전자인증 기관)를 쓰고, 연결이 안 되면 FreeTSA를 씁니다. 두 기관 모두 국제 표준(RFC 3161)을 따릅니다.

## 10. 용어 풀이

| 용어 | 쉬운 설명 |
|------|-----------|
| **고유 지문 (해시)** | 내용으로 만든 64자리 값. 내용이 같으면 늘 같고, 한 글자만 달라도 완전히 달라집니다 |
| **공인 시각 (타임스탬프)** | 외부 공인기관이 "이 시각에 이 지문을 받았다"고 전자 서명한 기록 |
| **등록번호** | 아이디어마다 붙는 고유 번호 (`IB-날짜-순번`) |
| **개정판** | 기존 아이디어를 발전시킨 새 버전. 원본은 그대로 남습니다 |
| **확인서** | 등록 사실을 한 장으로 정리한 인쇄용 문서 |
| **증명 파일** | 원문·첨부·전자 서명·검증 안내를 묶은 zip 파일 |
